# Contributing to swe-workflow-skills

swe-workflow-skills has one maintainer. Feedback and contributions are welcome:

- **Bugs**: [open an issue](https://github.com/SWEStash/swe-workflow-skills/issues/new/choose). Say what you asked, which skill ran, what you expected and what happened, and include the library version, how you installed it, the Claude Code version and the model.
- **Feature requests and skill ideas**: open an issue that describes the problem or the workflow you want guided.
- **Pull requests**: welcome. For a new skill or a larger change, open an issue first so the scope is agreed. Skills follow [AUTHORING](docs/AUTHORING.md) and ship their evals.
- **Security problems**: don't open a public issue. Report it privately through [GitHub's security advisories](https://github.com/SWEStash/swe-workflow-skills/security/advisories/new).

Coding agents start at [AGENTS.md](AGENTS.md). People, read in this order: this file, then [docs/HOW-WE-WORK.md](docs/HOW-WE-WORK.md) (how issues, PRs and releases are run), then for skill work [docs/AUTHORING.md](docs/AUTHORING.md) and [docs/EVALS.md](docs/EVALS.md).
